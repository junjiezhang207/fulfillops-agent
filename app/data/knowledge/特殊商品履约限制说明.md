特殊商品履约限制说明

文件性质：RAG 测试用仿真文档；所有公司名、人员、时效和阈值均为模拟数据，非真实企业制度。

# 1. 目的

说明冷链、大件、易碎、带电、贵重、定制等特殊商品在履约、售后和配送中的限制。

# 2. 适用范围

适用于所有含特殊商品标签的订单，优先级高于普通履约流程。

# 6. 业务规则与判断口径

6.1 冷链商品签收后非质量问题原则上不支持退货。

6.2 大件商品需提前预约配送，客户改约不得超过 2 次。

6.3 易碎商品必须双层包装并拍照留档。

6.4 带电商品跨境或偏远区域配送需按承运商限制表判断。

| 术语 | 定义 |
| --- | --- |
| OOS/缺货 | 可售库存小于订单需求数量，且预计补货时间不可满足承诺履约时效。 |
| 履约承诺时效 | 订单支付后至妥投或发货节点完成的承诺时间。 |
| 升级工单 | 需要仓配、客服主管、风控或供应链共同处理的跨部门记录。 |
| 冷链商品 | 需在指定温控范围内存储和配送的生鲜、医药或低温商品。 |
| 大件商品 | 单件体积、重量或安装需求超过普通快递承运能力的商品。 |
| 禁配区域 | 因承运商能力、政策或商品属性不能配送的省市区。 |

| 角色 | 主要职责 | 关键系统/表单 |
| --- | --- | --- |
| 客服专员 | 识别订单状态、安抚客户、发起补发/退款/换货/升级 | 客服工单系统、OMS |
| 仓库操作员 | 拣货、复核、打包、异常上报 | WMS、PDA |
| 履约运营 | 监控时效、协调仓配资源、复盘指标 | OMS、BI 看板 |
| 财务/风控 | 审核高风险退款、拒付、异常补偿 | 风控台、支付后台 |

| 步骤 | 触发条件/输入 | 处理动作 | 输出/记录 | 时限 |
| --- | --- | --- | --- | --- |
| 1 | 商品打标 | 商品上架时维护特殊属性和禁配区域 | 商品限制标签 | 上架前 |
| 2 | 订单校验 | 支付前校验地址、温控、承运商覆盖 | 可履约/不可履约结果 | 实时 |
| 3 | 仓库出库 | 按特殊包材、温控、拍照要求操作 | 出库记录 | 当天 |
| 4 | 配送交接 | 选择具备资质承运商并交接温控/安装资料 | 交接单 | 出库时 |
| 5 | 售后处理 | 按商品类型判断是否支持退换 | 售后结论 | 24小时内 |
