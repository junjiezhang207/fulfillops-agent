# 缺货履约规则

当订单出现 SKU 库存不足时，系统需要按照以下顺序处理：

1. 先判断是否存在同区域其他仓可售库存。
2. 如果存在同区域替代仓，优先建议跨仓调拨或跨仓发货。
3. 如果不存在同区域库存，但订单优先级为高，则允许扩大到跨区域仓库存检查。
4. 如果仍然无法满足，则进入缺货订单 SOP，并向用户提供延迟发货或拆单建议。
5. 对高优先级订单，必须在结果中明确标注人工复核建议。
