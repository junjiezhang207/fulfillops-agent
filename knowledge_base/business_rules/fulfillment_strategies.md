# 履约策略指南 — 4 种方案的使用场景

## 概述
系统为每个订单生成 4 种不同的履约方案，代表不同的成本-时间-质量权衡。本文档说明每种方案何时推荐、何时不推荐。

---

## 1. 快速方案 (FAST_TRACK)

### 特征
```
处理时间：2 小时
物流时间：24 小时（次日达）
物流方式：OVERNIGHT
总交期：26 小时
成本等级：⭐⭐⭐⭐⭐ (最高)
```

### 成本分解 (示例)
```
订单：700 件商品

仓库处理：700 × $5 = $3,500
运费：$100（次日达溢价）
打包费：$50（加急打包）
─────────────────────
总成本：$3,650
```

### 质量保证
```
质量等级：低风险
缺陷概率：< 1%
仓库质量评分：98.5%（最优仓库）
物流质量评分：99%（经验丰富物流商）
```

### 推荐场景
✅ **强烈推荐：**
- VIP 客户 + 急单 → 必须用
- 高价值订单（> $50K）+ 时间紧张
- 关键物资（生产线停工风险）
- 客户特别强调"必须 24 小时内"

✅ **适度推荐：**
- 一级客户 + 订单较大（> $20K）
- 高端产品（手机配件、医疗器械等）
- 竞争激烈的市场（需要突出速度优势）

### 不推荐场景
❌ **不推荐：**
- 新客户 + 小订单（< $1K）→ 成本太高，性价比差
- 成本敏感型订单 → 会导致订单无利可图
- 库存清理订单 → 应该用经济方案清库存
- 交期宽松的订单（> 7 天）→ 浪费成本

### 成本效益分析
```
快速方案 vs 平衡方案：

快速：26h，$3,650
平衡：76h，$2,190
差价：$1,460（63% 增加）
时间节省：50 小时

何时值得额外花 $1,460？
✓ VIP 客户保留（值得）
✓ 赶上产品发布期（值得）
✓ 突发订单补货（值得）
✗ 常规订单（不值得）
```

### 案例
```
订单：SO-2026-001
客户：阿里巴巴采购部（VIP）
金额：$60,000
交期：24 小时
特殊：易碎、防潮

决策：推荐快速方案
原因：VIP + 绝对时间紧张 + 高价值
结果：满足客户承诺，保持 VIP 关系
```

## 2. 平衡方案 (MIXED) ⭐ 推荐

### 特征
```
处理时间：4 小时
物流时间：72 小时（3-5 天）
物流方式：STANDARD
总交期：76 小时（3.2 天）
成本等级：⭐⭐⭐ (中等)
质量等级：⭐⭐⭐⭐ (高)
```

### 成本分解 (示例)
```
订单：700 件商品

仓库处理：700 × $3 = $2,100
运费：$50（标准运费）
打包费：$40（标准打包）
─────────────────────
总成本：$2,190

比快速方案便宜 40%！
```

### 质量保证
```
质量等级：低风险
缺陷概率：< 1%
仓库质量评分：96%（高质量仓库）
物流质量评分：98%（稳定物流商）
```

### 推荐场景
✅ **强烈推荐（系统默认）：**
- 所有一级客户订单
- 所有二级客户订单（非成本敏感）
- 一般的中等价值订单（$5K ~ $50K）
- 时间要求中等（3-5 天）

✅ **特别推荐：**
- 追求性价比的订单 → 成本和质量都不错
- 库存充足的 SKU → 无需加急，有充足缓冲
- 季节性订单 → 在产销平衡期使用
- 大订单拆分 → 部分急，部分可缓，分别用快速和平衡

### 不推荐场景
❌ **不推荐：**
- VIP 客户 + 急单 → 应该用快速
- 新客户 + 成本敏感 → 应该用经济
- 库存即将过期 → 应该用经济加速清库

### 性价比分析
```
平衡方案：成本 $2,190，时间 76h，质量 96%

vs 快速方案：
  • 便宜 $1,460（63% 省钱）
  • 多等 50 小时（2 天）
  • 质量略差（99% vs 96%）
  • 性价比最高！

vs 经济方案：
  • 贵 $745（34% 增加）
  • 快 92 小时（3.8 天）
  • 质量好（96% vs 91%）
  • 如果能多花 $745 换 4 天时间，值得！
```

### 案例
```
订单：SO-2026-002
客户：二级客户（常规）
金额：$15,000
交期：5 天（标准）
特征：常规电子配件

决策：推荐平衡方案
原因：一般订单 + 标准交期 + 需要质量保证
评分：72.8/100（最高综合评分）
成本：$2,190
```

## 3. 经济方案 (ECONOMY)

### 特征
```
处理时间：6 小时
物流时间：168 小时（7-14 天）
物流方式：ECONOMY
总交期：174 小时（7.2 天）
成本等级：⭐ (最低)
质量等级：⭐⭐⭐ (中等)
```

### 成本分解 (示例)
```
订单：700 件商品

仓库处理：700 × $2 = $1,400
运费：$20（经济运费）
打包费：$25（经济打包）
─────────────────────
总成本：$1,445

比快速方案便宜 60%！
比平衡方案便宜 34%！
```

### 质量保证
```
质量等级：中风险
缺陷概率：1-3%
仓库质量评分：92%（可接受仓库）
物流质量评分：90%（经济物流）

说明：质量可接受，但不如高级方案
```

### 推荐场景
✅ **强烈推荐：**
- 新客户 + 成本敏感订单 → 必须用
- 大额但时间不紧的订单 → 用经济方案成本更低
- 库存清理订单 → 用经济方案快速出货
- 季节性产品（过季）→ 清库存优于利润

✅ **适度推荐：**
- 标准产品 + 交期 7 天以上
- 低价值商品 → 对质量要求不高
- 库存积压超过 30 天 → 及时处理，避免贬值

### 不推荐场景
❌ **不推荐：**
- VIP 客户 → 违反承诺
- 一级客户 → 降低客户体验
- 高价值商品（> $20K）→ 质量风险太大
- 易碎品、冷链产品 → 经济物流无法保证

### 成本效益分析
```
经济方案：成本 $1,445，时间 174h，质量 92%

适用人群：
✓ 新客户（预算有限）
✓ 成本敏感型企业（家电厂商、服装商等）
✓ 库存清理（旧款、过季品）
✓ 低价值商品（配件、消耗品）

不适用人群：
✗ VIP 客户
✗ 高价值商品
✗ 对时间要求高
✗ 质量要求高
```

### 案例
```
订单：SO-2026-002
客户：小微企业 ABC（新客户）
金额：$5,000
交期：7 天（可延迟 3 天）
特征：成本敏感

决策：推荐经济方案（次优）
原因：新客户 + 成本敏感 + 交期宽松
评分：69.8/100（次高综合评分）
成本：$345（最低！）
利润：$300（比平衡方案少赚 $200，但可以成交）
```

## 4. 库存优化方案 (INVENTORY_OPTIMIZATION)

### 特征
```
处理时间：4 小时
物流时间：72 小时（3-5 天）
物流方式：STANDARD
总交期：76 小时（与平衡方案相同）
成本等级：⭐⭐⭐ (中等偏低)
目标：清理积压库存
```

### 成本分解 (示例)
```
订单：700 件商品

仓库处理：700 × $2.5 = $1,750
运费：$40
打包费：$35
─────────────────────
直接成本：$1,825

额外收益：
清理 30 天积压库存：
  - 仓储成本节省：$2,100
  - 库存贬值风险：$1,500
  ─────────────────────
  总收益：$3,600

建议折扣：5-10%（让出部分收益给客户）
```

### 何时生成此方案
```
条件 1：订单的 SKU 在某个仓库有 30+ 天的积压库存
条件 2：积压数量 ≥ 订单需求数量
条件 3：保质期还充足（或接近过期）

系统自动计算：
- 当前积压时间
- 预计贬值损失
- 仓储成本节省
- 建议给客户的折扣比例
```

### 推荐场景
✅ **强烈推荐：**
- 有积压库存需要清理
- 库存贬值风险（如：季节品接近过季）
- 仓库容量紧张，需要腾位置
- 客户对价格敏感，可以用折扣驱动采购

✅ **案例场景：**
```
场景 1：电商平台的季节品清库
订单来源：新客户采购冬装清仓货
我们库存：秋装积压 45 天，贬值风险高
方案：库存优化 + 8% 折扣
结果：一次性清出积压，避免贬值

场景 2：库存周转压力
订单来源：二级客户常规订单
我们库存：某 SKU 积压 60 天
方案：库存优化 + 6% 折扣
结果：加快周转，提高资金使用效率
```

### 不推荐场景
❌ **不推荐：**
- 没有积压库存 → 方案不存在
- 客户对价格不敏感 → 折扣吸引力小
- VIP 客户 → 不应该主动降价
- 库存快要过期 → 应该用经济方案加急出货

### 与其他方案的对比
```
库存优化 vs 平衡方案：

库存优化：$1,825 + 8% 折扣 = $1,679
平衡方案：$2,190

省钱：$511（23% 便宜）
额外收益：仓储成本节省 $3,600

何时选库存优化：
✓ 有积压库存 → 本方案更优
✓ 客户对折扣敏感 → 能提高成交率
✓ 库存成本压力大 → 需要加快周转
```

## 智能推荐逻辑

### 步骤 1：判断客户级别和订单特征
```
VIP + 急单？
  ├─ 是 → 推荐快速
  └─ 否 → 继续

一级客户？
  ├─ 是 → 推荐平衡
  └─ 否 → 继续

新客户 + 成本敏感？
  ├─ 是 → 推荐经济
  └─ 否 → 推荐平衡

有库存积压？
  ├─ 是 → 同时推荐库存优化
  └─ 否 → 忽略库存优化
```

### 步骤 2：计算综合评分
```
VIP + 急单订单：
  时间权重 50%，质量权重 30%，成本权重 20%
  → 快速方案评分最高（时间快）

新客户 + 成本敏感：
  成本权重 50%，质量权重 30%，时间权重 20%
  → 经济方案评分最高（成本低）

普通二级订单：
  时间权重 30%，质量权重 40%，成本权重 30%
  → 平衡方案评分最高（综合平衡）
```

### 步骤 3：按评分排序返回
```
评分从高到低：
1. 平衡方案 72.8/100 ← 推荐（最优综合评分）
2. 经济方案 69.8/100 ← 成本最低
3. 快速方案 54.8/100 ← 虽然快但太贵

客户可以选择任意方案
```

## 常见问题

**Q: 为什么快速方案不是最高分？**
A: 因为这个订单是新客户 + 成本敏感，在这种情况下系统权重成本 50%，时间只有 20%。虽然快速方案时间最短，但成本太高，综合评分反而最低。

**Q: 库存优化方案什么时候会出现？**
A: 只有当系统检测到该订单的某个 SKU 在某个仓库有 30+ 天的积压库存时，才会生成库存优化方案。

**Q: 能否强制使用某个方案？**
A: 可以。系统给出建议排序，但最终决定权在人（或 Agent）。可以覆盖推荐，选择其他方案。

**Q: 一个订单可以拆分成多个方案吗？**
A: 可以。比如订单有 500 件 A 商品（库存充足）+ 200 件 B 商品（库存紧张）。可以分别用不同方案：
- A 商品用库存优化方案（有积压）
- B 商品用平衡方案（优先保证交期）
然后分别发货。这是进阶的优化策略。
