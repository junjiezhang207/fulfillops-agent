# 风险评估指南 — 订单风险识别和缓释

## 概述
系统根据订单特征自动识别风险，并建议相应的缓释措施。本文档说明每种风险的含义及应对策略。

---

## 风险等级定义

### 低风险 (low_risk)
```
特征：订单特性标准，无特殊风险因素
风险标签数：0
典型订单：二级客户的常规订单
处理方式：标准流程
```

### 中等风险 (medium_risk)
```
特征：订单有 1-2 个风险因素
风险标签数：1-2 个
典型订单：新客户首次订单、较小高价值订单
处理方式：加强监控，考虑附加措施
```

### 高风险 (high_risk)
```
特征：订单有 2-3 个风险因素或 1 个严重风险
风险标签数：2-3 个
典型订单：新客户高价值订单、急单且库存紧张
处理方式：必须采取风险缓释措施
```

### 关键风险 (critical_risk)
```
特征：订单有多个严重风险因素
风险标签数：≥ 3 个或包含 critical 标签
典型订单：陌生客户超大订单、缺货 SKU
处理方式：需要人工审批，可能需要拒单或重新协商
```

## 常见风险标签

### 1. high_value（高价值）
**触发条件：** 订单金额 > $100,000

**风险：**
- 如果出现破损、丢失，损失巨大
- 需要有完整的保险和追踪机制
- 物流商责任更大

**缓释措施：**
- ✓ 强制进行质量检查（100% 检查）
- ✓ 选择高质量仓库和物流商
- ✓ 购买额外保险
- ✓ 加入 GPS 追踪
- ✓ 分批发货降低单次风险

**案例：**
```
订单：SO-2026-001（$60,000）
风险标签：high_value
缓释：
  ✓ 强制从上海仓库发货（质量 98.5%）
  ✓ 必须进行质量检查
  ✓ 购买 $1,000 保险
  ✓ 实时物流追踪
```

---

### 2. critical_deadline（关键交期）
**触发条件：** 距离交期 < 24 小时

**风险：**
- 时间极紧，任何延迟都导致违约
- 可能无法进行质量检查
- 仓库处理压力大，出错风险高
- 物流可能受天气、交通影响

**缓释措施：**
- ✓ 立即启动优先处理（跳过其他订单）
- ✓ 自动升至最高优先级
- ✓ 强制使用快速物流（OVERNIGHT）
- ✓ 分散风险：如仓库 A 不行，立即切换到仓库 B
- ✓ 准备应急预案（备用仓库、备用物流商）

**案例：**
```
订单：SO-2026-001
当前时间：2026-04-27 10:00
交期：2026-04-28 10:00
剩余时间：24 小时

风险标签：critical_deadline
处理：
  ✓ 优先级自动升至 10
  ✓ 物流强制 OVERNIGHT
  ✓ 不允许合并（避免延迟）
  ✓ 准备 3 个备用仓库
  ✓ 客户需提前 2 小时确认收货点
```

---

### 3. fragile_handling_required（易碎品）
**触发条件：** special_handling 包含"易碎"或"fragile"

**风险：**
- 运输中容易破损
- 退货率高（破损索赔）
- 需要专业包装和物流

**缓释措施：**
- ✓ 强制进行质量检查
- ✓ 使用高质量仓库（质量评分 > 95%）
- ✓ 购买易碎品专业保险
- ✓ 使用可靠物流商（破损率 < 0.5%）
- ✓ 增加包装费用（加固、缓冲材料）
- ✓ 提醒客户检查和签收流程

**案例：**
```
订单：SO-2026-001
特殊处理：易碎、防潮

风险标签：fragile_handling_required
缓释：
  ✓ 使用专业易碎品包装（+$100）
  ✓ 强制质量检查（100%）
  ✓ 物流保险：破损赔付
  ✓ 客户签收时要求当面检查
  ✓ 破损后 24 小时内报警
```

---

### 4. out_of_stock_SKU（缺货 SKU）
**触发条件：** 订单包含缺货或库存不足的 SKU

**风险：**
- 无法按承诺时间发货
- 需要与客户协商替代或延期
- 影响客户满意度

**缓释措施：**
- ✓ 立即与客户联系，说明库存情况
- ✓ 提供替代 SKU 方案（如果允许）
- ✓ 提议延期交期（给出明确时间）
- ✓ 提议拆分发货（现有库存先发，后续补发）
- ✓ 考虑调货（从其他仓库调配）
- ✓ 协商折扣以弥补延期影响

**案例：**
```
订单：SO-2026-003
SKU 清单：
  - SKU-A001：100 件（有 80 件，缺 20 件）
  - SKU-B002：50 件（完全缺货）

风险标签：out_of_stock_SKU-A001, out_of_stock_SKU-B002
缓释：
  ✓ 联系客户：A001 缺少 20 件，B002 缺货
  ✓ 方案 1：拆分发货（A001 现发 80 件，B002 待补货）
  ✓ 方案 2：替代（A001 用 A002 替代，B002 用 B001 替代）
  ✓ 方案 3：延期（等所有货都到再发，给予 5% 折扣）
  ✓ 客户选择方案后更新订单
```

---

### 5. urgent_high_value（急单+高价值）
**触发条件：** 订单类型 = URGENT AND 金额 > $50,000

**风险：**
- 既要快速，又要保证高价值产品的质量
- 压力最大，出错代价最高
- 仓库和物流压力最大

**缓释措施：**
- ✓ 分散风险：多仓库并行处理
- ✓ 双保险：购买加倍保险
- ✓ 专人跟踪：指派专门人员全程监控
- ✓ 实时通报：每 1 小时向客户通报进度
- ✓ 优质商家：仅使用最顶级的仓库和物流商
- ✓ 备用方案：准备好应急方案

**案例：**
```
订单：SO-2026-001
特征：VIP 急单，$60,000，易碎

风险标签：urgent_high_value, fragile_handling_required, high_value
缓释方案（全套）：
  ✓ 使用上海仓库（质量最佳 98.5%）
  ✓ 强制 OVERNIGHT 物流
  ✓ 100% 质量检查
  ✓ 购买 $2,000 保险
  ✓ 专业易碎品包装
  ✓ 指派专人监控（从仓库到客户）
  ✓ 每小时更新进度
  ✓ GPS 追踪
  ✓ 备用仓库已准备（广州仓库待命）
```

---

### 6. approaching_budget（接近预算）
**触发条件：** 已用预算 / 总预算 > 90%

**风险：**
- 客户可能因预算原因取消或修改订单
- 需要确保价格在预算范围内
- 追加费用可能被拒绝

**缓释措施：**
- ✓ 提前与客户确认价格（在生成方案时）
- ✓ 推荐经济方案（最低成本）
- ✓ 避免额外费用（如加急费、保险费）
- ✓ 询问是否可以调整数量
- ✓ 提议分期发货（分摊成本）
- ✓ 寻找成本优化空间（比如订单合并）

**案例：**
```
订单：SO-2026-004
预算：$5,000
方案成本：
  - 快速方案：$3,900（已占 78%）
  - 平衡方案：$2,190（已占 44%）
  - 经济方案：$1,445（已占 29%）

风险标签：approaching_budget（对快速方案）
处理：
  ✓ 不推荐快速方案（会超预算）
  ✓ 推荐平衡或经济方案
  ✓ 提前告知客户："预算内最佳选项是平衡方案"
  ✓ 避免后期追加费用导致超预算
```

---

### 7. new_customer_credit_risk（新客户信用风险）
**触发条件：** customer_level = NEW_CUSTOMER AND 金额 > $10,000

**风险：**
- 新客户信用记录未知
- 可能面临坏账风险
- 需要提前收款或付款方式确认

**缓释措施：**
- ✓ 要求付款方式确认（现金、转账、信用证等）
- ✓ 考虑要求预付款（比如 30% 预付）
- ✓ 与财务部核查客户背景
- ✓ 设置订单额度限制
- ✓ 定期跟进付款状态
- ✓ 必要时购买应收账款保险

**案例：**
```
订单：SO-2026-002
客户：小微企业 ABC（新客户）
金额：$5,000

风险标签：new_customer_credit_risk（如果 > $10,000）
处理：
  ✓ 联系客户确认付款方式
  ✓ 推荐 30% 预付，发货后 30 天内结清
  ✓ 要求营业执照和身份信息
  ✓ 财务部做背景调查
  ✓ 定期跟进收款（可安排提醒）
```

## 风险评分和优先级

### 风险评分计算
```
risk_score = Σ(风险权重)

单个风险权重：
- high_value：+20 分
- critical_deadline：+25 分
- fragile_handling_required：+10 分
- out_of_stock_SKU：+15 分
- urgent_high_value：+30 分（最严重）
- approaching_budget：+10 分
- new_customer_credit_risk：+15 分

总分映射：
- 0-10 分：低风险
- 11-30 分：中等风险
- 31-60 分：高风险
- 60+ 分：关键风险（需要人工审批）
```

### 处理优先级
```
关键风险订单 → 高风险订单 → 中等风险订单 → 低风险订单

在系统中：
关键风险：必须审批，可能拒单
高风险：建议采取缓释措施，可由经理审批
中等风险：推荐采取措施，可自动处理
低风险：标准流程，无需特殊处理
```

| 风险类型 | 风险等级 | 主要缓释措施 | 成本影响 |
|---------|---------|-----------|---------|
| high_value | 高 | 检查 + 保险 + 追踪 | +5% |
| critical_deadline | 关键 | 优先处理 + 快速物流 + 备用 | +10% |
| fragile_handling | 中等 | 专业包装 + 保险 | +3% |
| out_of_stock | 高 | 沟通 + 替代 + 延期 | 协商 |

| approaching_budget | 中等 | 选择经济方案 | 无增加 |
| new_customer | 中等 | 预付 + 背景调查 | 流程 |

## 自动化缓释建议

系统根据风险标签自动生成缓释建议：

### 示例 1：VIP 高价值急单
```
订单：SO-2026-001
风险标签：high_value, critical_deadline, fragile_handling_required

自动建议：
1. 选择仓库：上海仓库（最高质量 98.5%）
2. 物流方式：OVERNIGHT（强制快速）
3. 质检：100% 质量检查（必须）
4. 保险：购买 $2,000 保险覆盖
5. 包装：专业易碎品包装（+$100）
6. 追踪：GPS 实时追踪
7. 跟进：指派专人全程监控
8. 沟通：每小时更新客户
9. 备用：准备备用仓库和物流商
10. 决策：自动升级为最高优先级处理

预计成本增加：$2,100（保险 $2,000 + 包装 $100）
```

### 示例 2：新客户成本敏感订单
```
订单：SO-2026-002
风险标签：approaching_budget, new_customer_credit_risk

自动建议：
1. 方案选择：推荐经济方案（$1,445，占预算 29%）
2. 支付方式：要求确认（现金/转账/信用证）
3. 收款安排：建议 30% 预付
4. 背景调查：财务部核查客户信用
5. 额度限制：此客户暂时限额 $20,000
6. 跟进：7 天内确认付款状态
7. 保险：建议购买应收账款保险

风险等级：中等
处理难度：低（大多自动，需要客户确认付款方式）
```

## 常见问题

**Q: 系统会自动拒单吗？**
A: 不会。系统会识别关键风险，标记需要人工审批。人来决定是否拒单、修改订单或接受风险。

**Q: 缓释措施会增加多少成本？**
A: 取决于具体风险。保险通常 2-5%，专业包装 1-3%，加急物流 30-100%。系统会在推荐方案时显示额外成本。

**Q: 新客户订单一定要预付款吗？**
A: 不一定。取决于订单金额和客户信用评分。系统会建议，但可以根据实际情况调整。

**Q: 如何将新客户升级为低风险？**
A: 完成 1-2 个订单，按时付款，无退货。系统会逐步降低风险等级。6 个月后可升为二级客户，风险大幅下降。
