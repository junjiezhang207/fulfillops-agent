# 客户分级政策 — 供应链决策指导

## 概述
根据客户级别实施差异化的物流、质量、定价策略。这是系统核心的业务规则。

---

## VIP 客户 (vip)

### 定义
- 长期合作的大客户
- 年订单额 > 500 万元
- 信誉评分 ≥ 95%
- 如：阿里巴巴采购部、腾讯供应链等

### 优先级政策
- **默认优先级：** 8/10（最高）
- **规则调整：** 急单时自动升至 9-10
- **结果：** 在所有订单中最优先被处理

### 交期政策
- **目标交期：** 1 天
- **最大容许延迟：** 0 天（不允许延迟）
- **物流方式：** 强制次日达 (OVERNIGHT)
- **说明：** VIP 客户无法容忍延迟，必须保证时间

### 质量政策
- **质量等级：** SUPER（超级）
- **质检要求：** 必须检查
- **特殊处理：** 所有特殊需求必须满足
  - 易碎品专业包装
  - 防潮处理
  - 温控物流等
- **说明：** VIP 客户的产品往往是关键物资，质量绝不能有问题

### 订单合并政策
- **允许合并：** 否
- **等待时间：** 0 小时
- **说明：** VIP 客户不接受延迟合并，必须尽快独立发货

### 替代和返回政策
- **允许 SKU 替代：** 否（不可替代）
- **替代需批准：** 是（即使允许也需批准）
- **返回期限：** 30 天
- **运费承担：** 公司承担（免费退货）
- **说明：** VIP 客户可以无条件退货，提高客户满意度

### 定价政策
- **价格折扣：** 0.95（5% 折扣）
- **运费折扣：** 0.90（10% 折扣）
- **说明：** VIP 客户因为订单量大、频繁性强，获得最优定价

### 案例
```
订单：SO-2026-001
客户：阿里巴巴采购部（VIP）
金额：$60,000
交期：24 小时
特殊：易碎、防潮

应用规则：
  ✓ 优先级 5 → 10（VIP 最高级）
  ✓ 质量 STANDARD → SUPER（强制超级质量）
  ✓ 物流 STANDARD → OVERNIGHT（强制次日达）
  ✓ 合并 允许 → 不允许（VIP 不等待）
  ✓ 检查 无 → 必须（高价值品质要求）

结果：快速方案被推荐（虽然成本最高 $3,650）
```

## 一级客户 (first_tier)

### 定义
- 稳定合作的大客户
- 年订单额 100 万 ~ 500 万元
- 信誉评分 ≥ 90%
- 如：大型制造企业的采购部门

### 优先级政策
- **默认优先级：** 7/10（较高）
- **规则调整：** 急单时升至 8-9
- **结果：** 在普通订单中优先处理

### 交期政策
- **目标交期：** 2 天
- **最大容许延迟：** 1 天
- **物流方式：** 快递 (EXPRESS)
- **说明：** 一级客户有一定的灵活性，但仍需保证时间承诺

### 质量政策
- **质量等级：** PREMIUM（高级）
- **质检要求：** 可选（如有特殊需求则必须）
- **特殊处理：** 重点项目需要特殊处理

### 订单合并政策
- **允许合并：** 否（不鼓励）
- **等待时间：** 12 小时（可选）
- **说明：** 一级客户通常不喜欢合并等待

### 替代和返回政策
- **允许 SKU 替代：** 是
- **替代需批准：** 是（需要客户确认）
- **返回期限：** 14 天
- **运费承担：** 客户承担来回运费
- **说明：** 有条件支持替代，但需要额外确认

### 定价政策
- **价格折扣：** 0.98（2% 折扣）
- **运费折扣：** 0.95（5% 折扣）

## 二级客户 (second_tier)

### 定义
- 常规合作的中等客户
- 年订单额 10 万 ~ 100 万元
- 信誉评分 ≥ 80%
- 如：中小型企业、经销商

### 优先级政策
- **默认优先级：** 5/10（中等）
- **规则调整：** 稳定，很少调整
- **结果：** 与其他二级客户同等对待

### 交期政策
- **目标交期：** 5 天
- **最大容许延迟：** 2 天
- **物流方式：** 标准 (STANDARD)
- **说明：** 二级客户有较大的交期灵活性

### 质量政策
- **质量等级：** STANDARD（标准）
- **质检要求：** 仅在高价值或高风险时检查
- **特殊处理：** 常规处理

### 订单合并政策
- **允许合并：** 是
- **等待时间：** 48 小时（可以等待凑单以降低成本）
- **说明：** 二级客户有时愿意延迟换取成本优惠

### 替代和返回政策
- **允许 SKU 替代：** 是
- **替代需批准：** 否（可以直接替代，事后通知）
- **返回期限：** 7 天
- **运费承担：** 客户承担
- **说明：** 支持快速替代以加快配送

### 定价政策
- **价格折扣：** 1.00（无折扣）
- **运费折扣：** 1.00（无折扣）
- **说明：** 按标准价格计算

## 新客户 (new_customer)

### 定义
- 刚开始合作的客户
- 尚无完整的信誉评分
- 年订单额 < 10 万元或初次合作
- 如：小微企业、初次接触的采购商

### 优先级政策
- **默认优先级：** 3/10（较低）
- **规则调整：** 如表现良好可逐步升级
- **结果：** 在有库存压力时可能被延后

### 交期政策
- **目标交期：** 7 天
- **最大容许延迟：** 3 天（相对宽松）
- **物流方式：** 经济 (ECONOMY)
- **说明：** 新客户交期要求较低，利于降低成本

### 质量政策
- **质量等级：** STANDARD（标准）
- **质检要求：** 否（除非特别要求）
- **特殊处理：** 仅按最小要求处理

### 订单合并政策
- **允许合并：** 是
- **等待时间：** 72 小时（可以等待更久以优化成本）
- **说明：** 新客户通常对成本更敏感，愿意等待

### 替代和返回政策
- **允许 SKU 替代：** 是
- **替代需批准：** 否
- **返回期限：** 7 天
- **运费承担：** 客户承担（无免费退货）
- **说明：** 新客户的风险较高，限制免费退货

### 定价政策
- **价格折扣：** 1.05（5% 加价）
- **运费折扣：** 1.05（5% 加价）
- **说明：** 新客户信誉未建立，按加价计算来防风险

### 案例
```
订单：SO-2026-002
客户：小微企业 ABC（新客户）
金额：$5,000
交期：7 天（可延迟 3 天）
特殊：成本敏感

应用规则：
  ✓ 优先级 3 → 1（新客户最低级）
  ✓ 质量 STANDARD → STANDARD（无升级）
  ✓ 物流 STANDARD → ECONOMY（强制经济物流）
  ✓ 合并 允许 → 允许（新客户鼓励合并）
  ✓ 检查 无 → 无（成本优先）

结果：经济方案被推荐（成本最低 $345）
```

## 规则应用优先级

当一个订单同时满足多个条件时，按以下优先级应用规则：

1. **客户等级规则** (最高优先级)
   - VIP 规则总是覆盖其他规则
   
2. **订单类型规则**
   - 急单规则覆盖常规规则

3. **时间约束规则**
   - 紧急交期触发自动升级

4. **成本约束规则**
   - 对成本敏感的订单优先考虑经济方案

5. **质量要求规则** (最低优先级)
   - 质量要求是约束条件，不会被覆盖

### 示例冲突处理
```
订单特征：VIP 客户 + 成本敏感

规则冲突：
  VIP 规则 → OVERNIGHT + SUPER 质量（成本高）
  成本规则 → ECONOMY + STANDARD 质量（成本低）

应用结果：
  ✓ 客户等级优先于成本敏感
  ✓ 采用 OVERNIGHT + SUPER（VIP 优先）
  ✓ 但可在允许范围内争取成本优化

说明：客户等级是最高优先级，不能为了成本而妥协 VIP 服务承诺
```

## 客户升级路径

### 新客户 → 二级客户
**条件：**
- 连续 6 个月有订单
- 订单总额 > 10 万元
- 按时付款率 > 95%
- 投诉率 < 2%

**变化：**
- 优先级从 3 升至 5
- 价格从加价 5% 变为无折扣
- 交期从 7 天缩短至 5 天

### 二级客户 → 一级客户
**条件：**
- 连续 12 个月有订单
- 订单总额 > 100 万元
- 按时付款率 > 98%
- 投诉率 < 1%

**变化：**
- 优先级从 5 升至 7
- 价格给予 2% 折扣
- 交期从 5 天缩短至 2 天
- 允许 SKU 替代（需批准）
- 质量升至 PREMIUM

### 一级客户 → VIP 客户
**条件：**
- 连续 24 个月有订单
- 年订单额 > 500 万元
- 按时付款率 = 100%
- 零投诉或主动协商解决
- 战略合作意向

**变化：**
- 优先级升至 8
- 价格给予 5% 折扣
- 交期从 2 天缩短至 1 天
- 不允许延迟
- 质量升至 SUPER
- 禁止合并

## 常见问题

**Q: VIP 客户的订单为什么不能合并？**
A: VIP 客户对交期有最严格的要求（0 延迟），合并会导致延迟。为了保证 VIP 的服务承诺，必须独立发货。

**Q: 新客户为什么要加价 5%？**
A: 新客户信用记录未建立，风险较高。加价用来覆盖可能的坏账风险和额外的验证成本。

**Q: 二级客户可以升到一级客户吗？**
A: 可以。如果满足连续 12 个月、年订单额 > 100 万、按时付款率 > 98% 等条件，会自动升级。

**Q: 如何判断一个客户属于哪个级别？**
A: 在系统中，AdvancedOrderDetails.customer_level 字段明确指定。同时，客户信息中应该有升级历史和信誉评分。
