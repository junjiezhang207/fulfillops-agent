# SKU 特性和处理指南

## 概述
本文档定义了不同 SKU 的特性，包括保质期、特殊处理要求、质量标准等。这些信息用来指导仓库处理、物流选择和风险评估。

---

## SKU 特性分类

### 电子产品 (Electronics)

#### SKU-A001：主板模块
```
分类：核心电子部件
特性：
  - 保质期：24 个月（从出厂日期起）
  - 易损性：高（静电敏感，易损伤）
  - 特殊处理：防静电包装，防潮保护
  - 价值：中等（单价 ~$50）
  - 质量要求：PREMIUM（0.5% 缺陷率限制）

存储要求：
  - 温度：15-25°C
  - 湿度：40-50%
  - 防静电：必须使用防静电垫

物流要求：
  - 禁用物流方式：ECONOMY（太便宜，风险大）
  - 推荐方式：STANDARD 或以上
  - 保险：强烈建议

适用履约方案：
  ✓ 快速方案：可以
  ✓ 平衡方案：推荐
  ✓ 经济方案：不推荐（风险太大）
  ✓ 库存优化：如果没有积压超过 12 个月
```

#### SKU-B002：电源适配器
```
分类：配套电子产品
特性：
  - 保质期：36 个月
  - 易损性：低（相对耐用）
  - 特殊处理：普通包装即可
  - 价值：低（单价 ~$15）
  - 质量要求：STANDARD

存储要求：
  - 温度：常温
  - 湿度：无特殊要求
  - 防静电：不需要

物流要求：
  - 禁用物流方式：无
  - 推荐方式：任意
  - 保险：低价值，不必要

适用履约方案：
  ✓ 快速方案：可以
  ✓ 平衡方案：推荐
  ✓ 经济方案：完全可以
  ✓ 库存优化：可以
```

### 日用消费品 (FMCG)

#### SKU-C003：清洁剂
```
分类：快速消费品
特性：
  - 保质期：24 个月
  - 易损性：低（液体，但需防泄漏）
  - 特殊处理：液体包装标准（防泄漏，垫衬）
  - 价值：低（单价 ~$2）
  - 质量要求：STANDARD

存储要求：
  - 温度：常温（15-30°C）
  - 湿度：任意
  - 防泄漏：必须（用防泄漏垫衬）

物流要求：
  - 禁用物流方式：无
  - 推荐方式：任意
  - 保险：不必要
  - 特殊注意：液体，物流中可能受压力，需要垂直放置

适用履约方案：
  ✓ 任意方案都可以
  ✓ 库存优化：强烈推荐（快速消费，周转快）
```

#### SKU-D004：食品添加剂
```
分类：食品相关
特性：
  - 保质期：12 个月（较短）
  - 易损性：高（易受温度、湿度影响）
  - 特殊处理：温控、防潮
  - 价值：低（单价 ~$3）
  - 质量要求：PREMIUM（食品相关，严格标准）

存储要求：
  - 温度：10-20°C（冷链）
  - 湿度：40-60%（防止结块）
  - 防氧化：使用氮气包装

物流要求：
  - 禁用物流方式：ECONOMY（太久，可能变质）
  - 推荐方式：STANDARD 或 OVERNIGHT（取决于库存新鲜度）
  - 保险：强烈建议
  - 特殊要求：需要冷链物流（额外成本 +20%）

适用履约方案：
  ✓ 快速方案：推荐（保证新鲜）
  ✓ 平衡方案：可以（4 天可接受）
  ✓ 经济方案：不推荐（风险太大）
  ✓ 库存优化：特别推荐（保质期短，需快速清库）
```

### 其他常见 SKU

#### 易碎品（陶瓷、玻璃器皿）
```
特性：
  - 保质期：无（不易过期）
  - 易损性：极高（运输中容易破损）
  - 特殊处理：专业易碎品包装（$5-20/件）
  - 质量要求：PREMIUM（破损率 < 1%）

物流要求：
  - 禁用物流方式：ECONOMY（太颠簸）
  - 推荐方式：STANDARD 或以上
  - 保险：必须
  - 物流商选择：仅限有易碎品运输资质的

处理建议：
  ✓ 自动标记 fragile_handling_required
  ✓ 检查要求：100%（防止破损）
  ✓ 方案推荐：快速或平衡（不要经济）
  ✓ 保险：必须购买
```

#### 危险品（化学品）
```
特性：
  - 保质期：需要特别跟踪
  - 易损性：高（可能泄漏、爆炸）
  - 特殊处理：危险品标准处理
  - 质量要求：SUPER（零容错）

物流要求：
  - 禁用物流方式：任何非专业物流
  - 推荐方式：仅限危险品专业物流
  - 保险：必须（额外成本 +30%）
  - 许可证：需要危险品运输许可证
  - 文件：需要 MSDS（安全数据表）

处理建议：
  ✓ 需要专业资质处理
  ✓ 不允许与普通货混装
  ✓ 需要特殊仓库
  ✓ 建议人工审批（不自动处理）
```

#### 冷链产品（冷冻食品）
```
特性：
  - 保质期：短（取决于产品）
  - 易损性：极高（温度变化导致质量下降）
  - 特殊处理：全程冷链
  - 质量要求：SUPER

物流要求：
  - 禁用物流方式：ECONOMY, STANDARD（无法保证温度）
  - 推荐方式：OVERNIGHT（冷链快递）
  - 保险：必须
  - 成本：+40-60%（冷链运费高）
  - 时间限制：从仓库到客户 < 48 小时

处理建议：
  ✓ 建议快速方案（OVERNIGHT 冷链）
  ✓ 不建议库存优化（新鲜度优先）
  ✓ 需要冷库仓储
  ✓ 仓库中质量评分要求 > 95%
```

## SKU 替代品映射

### 替代品定义
- **完全替代**：功能完全相同，客户无感知
- **部分替代**：功能基本相同，但有轻微差异（需客户同意）
- **高级替代**：升级版本，价格更高但质量更好（可选）
- **降级替代**：低端版本，便宜但质量略差（需折扣）

### 替代规则
```
允许替代的条件：
✓ 客户等级 ≥ 二级客户
✓ 或订单类型为 FLEXIBLE
✗ VIP 客户通常不允许替代
✗ 紧急订单尽量避免替代
```

### 替代品清单

| 原 SKU | 替代品 | 替代类型 | 说明 |
|-------|-------|---------|------|
| SKU-A001（主板模块） | SKU-A002 | 完全 | 相同功能，新款型 |
| SKU-A001 | SKU-A003 | 高级 | 功能升级版，+10% 价格 |
| SKU-B002（电源） | SKU-B003 | 部分 | 功率略高，兼容 |
| SKU-C003（清洁剂） | SKU-C004 | 完全 | 相同配方，不同品牌 |
| SKU-D004（食品添加剂） | 无 | - | 食品相关，不能替代 |

## 存储期限和贬值模型

### 库存老化规则
```
库存在仓库的时间 → 贬值率

0-30 天：0% 贬值（完全价值）
31-60 天：5% 贬值（轻微过期风险）
61-90 天：10% 贬值（开始老化）
91-180 天：20% 贬值（明显老化）
181-365 天：50% 贬值（严重过期）
365+ 天：80% 贬值（几乎无价值）

对应处理：
- 0-30 天：标准销售
- 31-90 天：正常销售，准备库存优化方案
- 91-180 天：优先推荐库存优化方案（5-10% 折扣）
- 181+ 天：考虑清仓或销毁
```

### 成本优化建议
```
库存积压成本 = 仓储费 + 贬值损失 + 资金占用成本

示例：SKU-A001 积压 90 天
  - 仓储费：$0.5/件/天 × 90 天 = $45
  - 贬值损失：单价 $50 × 10% = $5
  - 资金占用：$50 × 5% 利率 / 12 × 3 月 = $0.6
  - 总成本：$50.6（占原价值的 101%！）

应对：
✓ 这个 SKU 如果库存超过 60 天，应该立即推库存优化方案
✓ 即使降价 5% ($47.5)，也比持续积压更划算
```

## 季节性产品处理

### 季节性定义
```
冬季产品：取暖设备、冬装、防滑用品等
  - 最优销售期：10 月 - 2 月
  - 过季月份：3 月 - 9 月
  - 贬值规则：过季后每月额外贬值 10%

夏季产品：空调、冷饮、防晒等
  - 最优销售期：5 月 - 8 月
  - 过季月份：9 月 - 4 月
  - 贬值规则：过季后每月额外贬值 10%

常年产品：日用品、电子配件等
  - 无季节性限制
  - 按库存老化规则计算贬值
```

### 处理建议
```
即将过季时：
✓ 提前 2 个月启动库存优化方案
✓ 积极推荐折扣清库（可接受 10-20% 折扣）
✓ 增加库存优化方案的推荐频率

完全过季后：
✓ 库存优化方案已无用（无人买）
✓ 建议清仓或捐赠处理
✓ 计为损失

案例：冬装
- 11 月：销售高峰
- 1 月：销售下降，开始库存优化推荐
- 2 月：加强库存优化推荐（可接受 15% 折扣）
- 3 月：过季，库存优化有限效果
- 4 月+：建议清仓处理
```

## 常见问题

**Q: 如何判断一个 SKU 是否易碎？**
A: 在订单中，如果 special_handling 包含"易碎"、"fragile"等字样，系统会自动标记。如果不确定，在创建订单时可以明确指定。

**Q: 过期的 SKU 还能销售吗？**
A: 取决于 SKU 类型。非食品类过期只是质量风险；食品相关的 SKU（包括添加剂）过期不能销售。系统会根据保质期自动判断。

**Q: 能否跨越两个等级替代？**
A: 一般不建议。比如 SKU-A001 需要替代时，推荐用 SKU-A002（同级），而不是直接跳到 SKU-A003（高级）。高级替代需要客户同意和额外付款。

**Q: 库存优化方案为什么对冷链产品推荐度低？**
A: 因为冷链产品的新鲜度最重要，库存越久质量下降越快。为了保证产品质量，不建议为了库存优化而延迟。应该优先考虑快速清货。
