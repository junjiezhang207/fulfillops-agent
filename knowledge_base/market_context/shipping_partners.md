## 概述

## 配送合作商列表

**覆盖地区：** 全国（含偏远地区）

#### 服务特性
```
时效：
  - 次日达 (OVERNIGHT)：主要城市 24h，三线城市 36h
  - 标准 (STANDARD)：3-5 天（全国）
  - 经济 (ECONOMY)：7-14 天（全国）

质量指标：
  - 破损率：< 0.5%（业界中等水平）
  - 延误率：< 2%
  - 投诉率：< 0.1%

费用：
  - 次日达：+50% 溢价（相对标准）
  - 标准：基准价格
  - 经济：-30% 折扣

支持：
  ✓ 实时追踪
  ✓ GPS 定位
  ✓ 保险服务
  ✓ 签约大客户有折扣
```

#### 使用建议
```
适合使用：
✓ 一般订单（时间要求中等）
✓ 中等价值商品
✓ 全国配送

不适合使用：
✗ 易碎品（破损率不够低）
✗ 冷链产品（无冷链服务）
✗ VIP 急单（质量不是最佳）
```

#### 评分
```
总体评分：4.0 / 5.0
  - 时效性：4.0（稳定，但不是最快）
  - 质量：4.0（一般，有一定破损率）
```

## 物流方式与合作商映射

### OVERNIGHT（次日达）
```
推荐优先级：
1. 顺丰速运（SF Express）- 最可靠
2. 德邦物流（Debang）- 覆盖面广
3. 圆通速递（YTO）- 备选

选择标准：
- VIP 订单 → 顺丰（不容协商）
- 高价值订单 → 顺丰（质量最好）
- 普通急单 → 德邦（成本 vs 质量平衡）
```

### STANDARD（标准 3-5 天）
```
推荐优先级：
1. 德邦物流（Debang）- 质量好
2. 圆通速递（YTO）- 价格便宜
3. 中通快递（ZTO）- 最经济

选择标准：
- 一级客户 → 德邦（质量保证）
- 二级客户 → 德邦或圆通（按成本选）
- 新客户 → 圆通（成本敏感）
```

### ECONOMY（经济 7-14 天）
```
推荐优先级：
1. 中通快递（ZTO）- 最便宜
2. 圆通速递（YTO）- 备选
3. 德邦物流（Debang）- 不推荐（偏贵）

选择标准：
- 成本优先 → 中通（最便宜）
- 有覆盖问题 → 圆通（地区更全）

注意：
- 不要给 VIP 用经济物流
- 不要给易碎品用经济物流
- 成本敏感时用此方案
```

### BULK（整车 21+ 天）
```
推荐物流商：
- 德邦整车服务
- 公路局物流

选择标准：
- 订单量 > 10 吨
- 目的地固定
- 时间完全灵活
- 成本优先
```

### 冷链
```
唯一选择：顺丰冷运（SF Cool Chain）
无替代方案
必须预约
```

## 应急物流方案

### 当首选物流商不可用时
```
场景 1：顺丰爆满（紧急订单无法次日达）
→ 替代：德邦次日达（可能延迟到 36h）
→ 通知客户，协商补偿方案

场景 2：圆通某地区无覆盖
→ 替代：德邦（覆盖范围最全）
→ 成本会增加，需要与客户沟通

场景 3：突发天气影响物流
→ 启动应急预案：
  ✓ 更换路线
  ✓ 更换物流商
  ✓ 调整时间预期
  ✓ 主动通知客户
```

## 与系统的集成

### 自动选择逻辑
```python
if 订单.shipping_method == ShippingMethod.OVERNIGHT:
    if 订单.customer_level == CustomerLevel.VIP:
        物流商 = 顺丰  # VIP 必须用最好的
    elif 订单.total_amount > 50000:
        物流商 = 顺丰  # 高价值必须用最好的
    else:
        物流商 = 德邦  # 普通急单用德邦

elif 订单.shipping_method == ShippingMethod.STANDARD:
    if 订单.customer_level == CustomerLevel.VIP:
        物流商 = 德邦  # VIP 用优质物流商
    elif 订单.cost_sensitive:
        物流商 = 圆通或中通  # 成本敏感用便宜的
    else:
        物流商 = 德邦  # 默认中等质量

elif 订单.shipping_method == ShippingMethod.ECONOMY:
    物流商 = 中通  # 经济方案必须最便宜

if 订单.special_handling 包含 冷链:
    物流商 = 顺丰冷运  # 冷链无替代
```

## 常见问题

**Q: 为什么 VIP 订单强制顺丰？**
A: 顺丰破损率最低（0.2%），质量最稳定。对 VIP 这种高价值、高承诺的订单，不能冒风险。

**Q: 能否协商物流商折扣？**
A: 可以。大客户（月均费用 > $50,000）可以与物流商直接协商。系统会记录协商折扣，自动在计价中应用。

**Q: 冷链产品一定要顺丰吗？**
A: 是的。顺丰冷运是系统中唯一支持的冷链服务。其他物流商无法保证温度控制。

**Q: 物流商爆满怎么办？**
A: 启动应急方案。优先级：顺丰 → 德邦 → 圆通 → 中通。如果全部爆满，与客户协商延迟交期。
